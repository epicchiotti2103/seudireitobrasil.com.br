Política de Privacidade

Última atualização: janeiro de 2025

1. Informações gerais

Esta Política de Privacidade descreve como o Seu Direito Brasil ("nós", "nosso") coleta, utiliza e protege as informações dos visitantes deste site, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

2. Dados coletados

2.1 Dados de navegação

Coletamos automaticamente dados anônimos de navegação por meio de ferramenta de analytics (PostHog, hospedado via proxy próprio). Isso inclui: páginas visitadas, tempo de permanência, dispositivo e navegador utilizados, país de origem e página de referência.

2.2 Dados fornecidos voluntariamente

Caso você entre em contato conosco via formulário ou e-mail, coletamos os dados informados: nome, e-mail e conteúdo da mensagem.

2.3 Dados que NÃO coletamos

Não coletamos dados sensíveis (origem racial, opinião política, dados de saúde, etc.), não utilizamos cookies de terceiros para publicidade e não compartilhamos dados pessoais com anunciantes.

3. Finalidade do tratamento

Os dados coletados são utilizados exclusivamente para: entender o comportamento de navegação e melhorar nosso conteúdo; responder mensagens enviadas pelo formulário de contato; e garantir a segurança e o funcionamento do site.

4. Base legal (LGPD)

O tratamento de dados pessoais é realizado com base no legítimo interesse do controlador (Art. 7º, IX da LGPD) para dados de navegação, e no consentimento do titular (Art. 7º, I) quando dados são fornecidos voluntariamente via formulário.

5. Compartilhamento de dados

Não vendemos, alugamos ou compartilhamos dados pessoais com terceiros, exceto: prestadores de serviço essenciais para operação do site (hospedagem, analytics); e quando exigido por lei ou ordem judicial.

6. Seus direitos (Art. 18 da LGPD)

Você tem direito a: confirmar a existência de tratamento de dados; acessar seus dados; solicitar correção de dados incompletos ou inexatos; solicitar anonimização, bloqueio ou eliminação de dados desnecessários; solicitar a portabilidade dos dados; revogar o consentimento a qualquer momento.

Para exercer seus direitos, envie e-mail para contato@seudireitobrasil.com.br com o assunto "LGPD — [seu pedido]".

7. Retenção de dados

Dados de navegação anônimos são retidos por até 12 meses. Dados de contato (nome, e-mail, mensagem) são retidos por até 24 meses após a última interação, exceto se você solicitar a exclusão antes.

8. Segurança

Adotamos medidas técnicas e administrativas para proteger os dados pessoais: conexão criptografada via HTTPS/TLS; analytics via proxy próprio (não enviamos dados diretamente para terceiros); e acesso restrito aos dados coletados.

9. Alterações nesta política

Esta política pode ser atualizada periodicamente. A data da última atualização será sempre indicada no topo da página.

10. Contato

Para dúvidas sobre esta política ou sobre o tratamento dos seus dados: contato@seudireitobrasil.com.br

Informação jurídica confiável, escrita de forma acessível e revisada por profissionais do direito.
